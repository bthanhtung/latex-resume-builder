# Security policy

LaTeX Resume Builder only runs local build scripts on files you provide. If you find a
security problem (for example a script that could delete files outside the project or
run untrusted commands), please report it privately through
[GitHub security advisories](https://github.com/bthanhtung/latex-resume-builder/security/advisories/new)
rather than in a public issue. You will get an acknowledgement within a few days.
